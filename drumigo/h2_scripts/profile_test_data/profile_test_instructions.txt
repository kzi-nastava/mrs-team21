How to Run:
-----------

1. Start the Spring Boot application (it will create the schema automatically)

2. Access H2 Console:
   - URL: http://localhost:8080/h2-console
   - JDBC URL: jdbc:h2:mem:drumigo
   - User Name: sa
   - Password: (leave empty)

3. Click "Connect"

4. Copy and paste the contents of profile_test_data.sql into the SQL statement area

5. Click "Run" to execute the script

6. Verify data was inserted:
   SELECT * FROM users;
   SELECT * FROM drivers;
   SELECT * FROM passengers;
   SELECT * FROM admins;
   SELECT * FROM vehicles;

Testing in Frontend:
--------------------

1. Update profile-page.component.ts line ~80 to use different userId:
   const userId = 2; // Change to 1, 2, 3, 4, 5, or 6

2. Start frontend: npm start

3. Navigate to: http://localhost:4200/profile

4. Verify:
   - Passenger (userId=1 or 6): Shows personal info, no vehicle section
   - Driver (userId=2, 4, or 5): Shows personal info + vehicle section with details
   - Admin (userId=3): Shows personal info, no vehicle section
